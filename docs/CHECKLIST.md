# Checklist Kandidat Proyek — Ruwa Jurai

> Format kerja sama dengan jadwal penilaian GEMATIK 2026 Web Design Competition.

## Kriteria Penilaian

1. **UI/UX** — desain, tipografi, aksesibilitas, responsif, interaksi.
2. **Fungsionalitas** — fitur bekerja, state, offline, performance.
3. **Konten** — akurasi, kelengkapan, kepatuhan budaya, referensi.
4. **Dokumentasi** — proposal, demo, panduan instalasi, catatan etika.

## Peta fitur → kriteria

| Fitur | Kriteria |
| --- | --- |
| Hero bergerak + mascot | UI/UX, fungsionalitas (drag) |
| Sorotan rail | UI/UX, fungsionalitas |
| Ensiklopedia + modal | Konten (kelengkapan), a11y |
| Kuliner + resep | Konten, fungsionalitas |
| Peta interaktif | UI/UX, fungsionalitas, konten |
| Gawi + badge + XP | UI/UX, fungsionalitas |
| Kamus + converter aksara | Konten, a11y |
| Agenda + ICS | Fungsionalitas |
| Tema/teks/gerak/suara | UI/UX, a11y |
| PWA/offline | Fungsionalitas |
| SDG + etika | Konten, dokumen |

## Risiko konten

- Klaim adat memakai bahasa hati-hati (“sering digambarkan”, “dapat berbeda”).
- Aksara display helper (bukan orografi penuh).
- Nama Sai & atribut maskot masih “working name”.
